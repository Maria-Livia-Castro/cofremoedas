# Cofre de Moedas 💰

Aplicação em Java que simula um cofre de moedas com funcionalidades de adicionar, remover, listar e converter moedas estrangeiras (dólar, euro) para real.

## 🛠 Tecnologias
- Java
- Programação Orientada a Objetos (POO)
- Polimorfismo, Herança, Encapsulamento

## 📌 Funcionalidades
- Adicionar moedas ao cofre
- Remover moedas do cofre
- Listar todas as moedas
- Calcular o valor total convertido em real

## 🚀 Como executar
1. Clone o repositório
2. Compile os arquivos `.java`
3. Execute o programa no terminal

## 📷 Exemplo
```bash
> Adicionar moeda: 10 dólares
> Adicionar moeda: 5 euros
> Listar moedas
> Calcular total em real
